# 📄 Papr

> **Fast, private, 100% offline mobile PDF & document toolkit for Android.**

Papr runs all PDF tools (30 tools including Merge, Split, Compress, AES-256 Lock/Unlock, Hardware OCR, Word/Excel Converters, Grayscale, Margin Adjustments, Watermark, and Document Scanner) **100% locally on your phone's CPU/NPU**. Zero cloud egress, zero analytics, and zero tracking.

## 🔒 Privacy & Architecture

- **100% Local Processing:** Uses native C++ QPDF and embedded document engines directly on device.
- **Zero Cloud Dependencies:** Operates in Airplane mode with zero network permissions required for core operations.
- **Dynamic Theming:** Custom accents, Classic Twitter Blue theme tokens, and OLED pitch-black dark mode.
- **Fast & Responsive:** Hardware-accelerated 60fps UI built with React Native and Uniwind Tailwind.
